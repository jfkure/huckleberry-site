# Huckleberry Innovations — Website

Source for [huckleberryinnovations.com](https://huckleberryinnovations.com), home of open-source range and tactical gear, starting with the **Shot Timer MK1**.

The site is a static site deployed to Netlify automatically on every push to the main branch.

## Huckleberry is open source

Huckleberry products are developed in the open. Firmware, hardware files, and user manuals are published on GitHub:

- **Shot Timer MK1**: [jfkure/shot-timer-mk1](https://github.com/jfkure/shot-timer-mk1)
  - Firmware: GPL-3.0
  - Hardware: CERN-OHL-S-2.0
  - Documentation: CC BY-SA 4.0

More products are on the way.
